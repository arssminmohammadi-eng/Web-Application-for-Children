# سه‌زبانه | کلمه‌های کوچک، دنیای بزرگ

یک اپلیکیشن PWA برای یادگیری واژه‌های فارسی، عربی و انگلیسی با موضوعات اعداد،
خانواده، رنگ‌ها، شکل‌ها و جانورها. درس‌های بازشده، پیشرفت و تنظیمات روی دستگاه
ذخیره می‌شوند؛ هیچ داده‌ای به سرور ارسال نمی‌شود.

## اجرا

```bash
npm install
npm run dev
```

برای بررسی:

```bash
npm run typecheck
npm run lint
npm run build
```

## ساخت صدا با Piper

اسکریپت `scripts/generate-audio.ts` واژه و جمله‌های تمام فایل‌های
`data/words/*.json` را به MP3 مونو با نرخ 22,505 هرتز و 80 کیلوبیت بر ثانیه
تبدیل می‌کند. ابتدا Piper TTS و FFmpeg را روی سیستم نصب کنید، سپس اجرا کنید:

```bash
npm run audio:generate
```

مدل‌های زیر در نخستین اجرا از مخزن
[`rhasspy/piper-voices`](https://huggingface.co/rhasspy/piper-voices) دریافت
می‌شوند و در `models/piper/` نگهداری می‌شوند:

- فارسی: `fa_IR-amir-medium`
- عربی: `ar_JO-kareem-medium`
- انگلیسی: `en_US-lessac-medium`

خروجی‌های واژه در `public/audio/{fa,ar,en}/{topic}/{id}.mp3` و جمله‌ها با پسوند
`-sentence.mp3` کنار آن‌ها ذخیره می‌شوند. فایل‌های موجود دوباره ساخته نمی‌شوند؛
برای بازسازی همهٔ فایل‌ها از `npm run audio:generate -- --force` استفاده کنید.
در نبود فایل، رابط کاربری از صدای گفتاری مرورگر با زبان مناسب استفاده می‌کند.

## PWA، GitHub و Vercel

Service Worker دستی، صفحهٔ اصلی، صفحه‌های درس بازدیدشده و منابع بارگذاری‌شده را
در حافظهٔ آفلاین نگه می‌دارد. برای انتشار، این پوشه را به یک مخزن GitHub متصل
کنید و مخزن را در Vercel وارد کنید؛ تنظیمات پیش‌فرض Next.js برای build کافی است
و هر push به شاخهٔ اصلی به‌طور خودکار deploy می‌شود.
